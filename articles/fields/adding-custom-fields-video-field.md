## Purpose

The Video field allows selection of a video file from a media folder.
It also allows selection of an image to act as a poster for the video,
typically the first frame of the video.

## Field Creation

Common field parameters are described in a separate article.

* **Title** The title is seen and used in the list of fields.
* **Label** This is what is displayed in the output. If left empty it is set
from the content of the Title field but can be changed.

![video field creation](../../../en/images/fields/adding-custom-fields-video-field/01-fields-video-edit.png)

**Note:** In this example, inclusion of the field type in the Title is for
demonstration purposes only. Leave it out in your own field titles.

## Data Entry

In use the Video field is simple. You select the required video file using a
media picker. 

The following screenshot shows an audio file selected:

![video field data entry](../../../en/images/fields/adding-custom-fields-video-field/02-fields-video-data-entry.png)

Fields only appear in an article if populated in the article data entry form.
